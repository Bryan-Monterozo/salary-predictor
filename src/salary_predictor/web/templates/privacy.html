Our local web skeleton keeps the profile flow simple, transparent and limited.

What happens to a profile?

This version processes manually entered details only for the active request. Your job title, skills, and education are not written to a dataset or added to model training. The session cookie holds a form-security token, not your career profile.

Are résumés uploaded?

No. Résumé uploading is disabled until the secure extraction workflow is implemented and tested.

What about salary predictions?

No experimental model is loaded by the website. The default result is unavailable unless a trusted application operator injects a verified provider in a controlled test or future approved release.

Browser and network

The interface uses local JavaScript and styles. It also references Bootstrap CSS from a third-party CDN; the custom site styles remain available when it cannot be reached. Do not enter sensitive personal identifiers.

Where is form state kept?

Review and result pages pass your profile with your form submission; there is no local database or stored draft in this version. Do not use this shell as a production-ready privacy or security system.
